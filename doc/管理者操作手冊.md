## 一、管理者角色與權限

系統採**多重身分（roles）**設計，一個帳號可同時擁有多個身分：

| 身分 | 說明 |
|------|------|
| `user` | 基線身分，所有人都有 |
| `teacher` | 可開課授課 |
| `admin` | 可進入後台、管理會員與課程 |
| `superadmin` | 最高權限，額外可調整系統基本設定（如學習階層深度） |

權限判定集中於 `lib/auth-roles.ts`：

- `canAccessAdmin(roles)` — 是否可進後台（admin / superadmin）
- `canTeach(roles)` — **開課入口**判定：是否具 teacher / admin / superadmin 身分（只看身分）。
  - ⚠️ 這只是第一層。進入開課精靈後，**Step 1 還會逐門課檢查是否已結業該課程**（admin / superadmin 豁免），未結業的課程無法選取。詳見《老師手冊》〈講師身分與授課資格〉。
- `isSuperadmin(roles)` — 是否為最高管理員

> ⚠️ 為避免自鎖，系統**禁止移除自己帳號的 admin / superadmin 身分**。

## 二、進入後台

1. 以管理者帳號登入。
2. 點選右上角 **後台管理**（僅 admin / superadmin 可見），進入 `/admin`。
3. 後台首頁為**功能按鈕網格**，包含：儀錶板、開課管理、會員管理、教材管理、課程目錄、系統設定等入口。

## 三、後台儀錶板

路徑：`/admin/dashboard`

**統計卡片（6 張）**：

| 卡片 | 說明 |
|------|------|
| 總會員數 | 系統中所有會員（User）總數 |
| 啟動靈人講師資格人數 | **同時**具備 `teacher` 身分 **且**已結業「啟動靈人」的不重複人數 |
| 啟動豐盛講師資格人數 | **同時**具備 `teacher` 身分 **且**已結業「啟動豐盛」的不重複人數 |
| 開課中課程總數 | 招生中課程（尚未開始上課、未取消、未結業） |
| 進行中課程總數 | 已開始上課、未取消、未結業的課程 |
| 已結業課程總數 | 已完成結業的課程 |

> ⚠️ 講師資格人數採**嚴格 `teacher` 身分**判定：僅具 admin / superadmin 而未加掛 teacher 者**不計入**。此定義與「老師手冊」的兩層授課把關一致。

## 四、會員管理

路徑：`/admin/members`

### 清單功能
- ⚠️ **未輸入任何條件時不顯示清單**：為避免一次載入全部會員拖慢頁面，需先**輸入搜尋**或**選擇任一篩選**，清單才會出現。
- **搜尋**：搜尋姓名、暱稱、Email、**啟動編號**（輸入框 debounce 300ms）。
- **篩選下拉**（可與搜尋並用，採 AND）：
  - **性別**：全部／男／女／未指定
  - **身分**：全部／一般會員／講師／管理者／超級管理者（「包含」語意，例如選「講師」會列出所有具講師身分者）
  - **所屬教會**：全部／各教會／其他／無
- **分頁**：每頁 **30 筆**，下方有「上一頁／下一頁」，並顯示「第 X / Y 頁」與符合條件**總筆數**；變更搜尋或篩選會回到第 1 頁。
- **排序**：依加入日期、其次姓名。
- 列表顯示會員**身分 Badge**（多重身分一併呈現）。
- **匯出**：「匯出 N 筆」會依**目前所有篩選條件**匯出（N = 符合條件總數，非僅當頁 30 筆）；「匯出全部」則忽略條件匯出所有會員。

### 新增會員
1. 點選 **新增會員**。
2. 系統會自動：核發**啟動編號** + 產生**臨時密碼** + 加入 Email 白名單。
3. ⚠️ **臨時密碼僅顯示一次**，請立即複製交付給該會員。

### 會員詳情
路徑：`/admin/members/[id]`，以 Tabs 呈現：

- **基本資料**：姓名、英文名稱、性別、顯示名稱偏好、所屬教會、學習階層、**授課老師編號（teacherNo）**。
- **學習階層（師生傳承樹）**：以縮排樹狀呈現上一層老師與下方 N 層學生（僅限「啟動靈人」、且以已結業 `graduatedAt` 為準）。展開層數由系統設定 `hierarchy_depth` 控制。

### 重設密碼
- 在會員清單或詳情頁點選 **重設密碼**（AlertDialog 二次確認）。
- 重設後系統會**重新顯示一組臨時密碼**，請複製交付會員。會員下次登入須重新設定密碼。

### 刪除會員
- 受環境變數 `ENABLE_MEMBER_DELETE` 控制，啟用時才出現 **刪除** 按鈕（AlertDialog 二次確認）。

## 五、多重身分管理

於**會員詳情頁**編輯該會員身分（`updateMemberRoles`）：

- 可勾選 / 取消 `teacher`、`admin`、`superadmin`（`user` 為基線恆存在）。
- 賦予 `teacher` 會讓該會員**看到「新增授課」入口**（第一層）；但實際能開哪門課，仍受開課精靈 Step 1 的**結業證書**檢查（第二層，admin/superadmin 才豁免）。若該講師無任何結業證書，入口可見但每門課都無法選取。
- ⚠️ 不可移除**自己帳號**的 admin / superadmin 身分。
- 身分變更**即時生效**：JWT callback 於每次請求自 DB 同步角色，無需該會員重新登入。

## 六、Email 白名單與存取控制

- 只有列在白名單（`WhitelistedEmail`，`isActive = true`）的 Email 才能透過 Google OAuth 登入。
- 透過後台「新增會員」建立帳號時會**自動加入白名單**。
- 未授權的 Email 登入會被導向 `/login?error=NotWhitelisted`。

> 若有人反映 Google 登入顯示「未授權」，代表其 Email 不在白名單，請以「新增會員」建立或聯絡技術人員加入名單。

## 七、開課管理

路徑：`/admin/course-sessions`（全站所有開課，admin+）

- **文字搜尋**：課程名稱 / 講師 / 學員。
- **下拉篩選**：課程名稱、進度狀態、日期區間。
- 顯示**總筆數**，預設列出前 30 筆。
- 點擊課程**另開新視窗**進入課程詳情頁，可協助講師處理核准、結業、取消等操作。

### 後台變更課程狀態
列表中每筆課程卡片**下方**有一個**狀態下拉選單**，管理者可直接變更該課程狀態（不必進課程詳情頁、不受開課者本人限制）：

- 可選狀態：**招生中 / 進行中 / 已取消**，可**任意方向**切換（含回退，例如 已取消 → 招生中）。
- ⚠️ **不提供「已結業」**：結業仍須由講師走課程詳情頁的結業流程（逐學員勾選），以保護學員結業證書。已結業的課程，下拉會以**停用**狀態顯示「已結業」，無法在此變更。
- 變更**即時生效**，且**不會**發送通知給講師或學員（屬行政更正）。
- 以「已取消」變更時，取消原因會記為「（管理者後台調整）」。

> 注意：把「已結業」以外的狀態任意切換是被允許的；若將已結業課程改回其他狀態（需先非已結業才可操作），學員既有的結業證明不會被一併移除。

## 八、教材申請管理

路徑：`/admin/materials`

### 流程角色
教材由**學員申請** → **管理者寄送** → **學員確認收件**。

### 後台操作
- 列表顯示各筆申請與**狀態 Badge**（待寄送 / 已寄送等）。
- 展開**詳情**可查看：收件者、取貨方式、門市資訊（7-11 / 全家，透過 ECPay 門市選擇器取得）、地址、書本數量（依學員繁／簡體選購自動統計）。
- **編輯**：點 **編輯** 開啟 `MaterialOrderEditDialog` 修改申請內容（`updateMaterialOrderAdmin`）。
- **確認寄送**：點 **確認已寄送** 標記出貨。

### 多地址寄送
- 教材可採**單一地址**或**多地址**寄送（`ShipMode`）。
- 多地址時，書本依繁／簡本數分配至各批次（`MaterialShipment`）。
- 後台需**逐批次確認寄送**；當所有批次都寄完，系統自動設定整筆訂單為已寄送（`shippedAt`）。

### 出貨單列印
- 路徑：`/admin/materials/[id]/print`。
- 點列表的 **列印** 按鈕產生出貨單（收件者、寄件方式、地址、書本數量）。
- 多地址時**每批次列印一份**。

## 九、課程目錄管理

路徑：`/admin/settings?tab=courses`（系統設定 → 課程目錄管理分頁）

`CourseCatalog` 是課程的**唯一資料來源**，可維護：

- **課程名稱（label）**
- **簡介（description）**：選填，列表以兩行截斷顯示。
- **是否啟用（isActive）**：⚠️ 唯有啟用的課程才能被講師選為開課目標。
- **顯示順序（sortOrder）**。
- **先修課程（prerequisites）**：多選自關聯。系統採**累積式**先修（例如「啟動靈人 N」需先修 1..N-1）。

> 先修驗證會在學員報名時生效（`checkPrerequisites`），admin / superadmin 開課時豁免先修限制。

## 十、教會代碼維護

路徑：`/admin/settings?tab=churches`（系統設定 → 教會代碼維護分頁，admin+）

- 對 `Church` 進行新增 / 編輯 / 停用 / 刪除（inline CRUD）。
- **停用**：保留與會員的關聯，僅不再出現在新選單。
- **刪除**：若仍有會員關聯該教會，系統會**拒絕刪除**（請改用停用）。
- 會員在個人資料頁可從此清單選擇所屬教會，或選「其他」自填、「無」。

---

## 十一、系統基本設定

路徑：`/admin/settings?tab=basic`（系統設定 → 基本設定）

- **學習階層深度（`hierarchy_depth`）**：⚠️ **僅 superadmin** 可調整。
  - 控制會員詳情頁「師生傳承樹」往下展開的層數。
  - 有效範圍 **1–10**，預設 `3`。
- 設定以 `AdminSetting`（key/value）儲存。

---

## 十二、會員 Excel 匯出

路徑：會員管理頁的 **匯出** 按鈕（後端 `/api/admin/members/export`）

- 可選擇 **匯出 N 筆**（依當前 `?q=` 篩選結果）或 **匯出全部**。
- 匯出 13 欄欄位，含中文化的性別、身分（全部身分）、教會、**授課老師編號**等。
- 非 admin 呼叫會回 401。

## 十三、常見管理情境

### 情境 A：新成員加入機構
1. 後台 **會員管理 → 新增會員**。
2. 複製系統顯示的**臨時密碼**交付對方（僅顯示一次）。
3. 對方首次登入走 Onboarding（設定密碼 → 填資料 → 取得啟動編號）。

### 情境 B：指派某人成為講師
1. 進入該會員的**詳情頁**。
2. 在多重身分編輯區勾選 `teacher` 並儲存。
3. 變更即時生效，對方即可看到「新增授課」入口。

### 情境 C：會員忘記密碼
- 若可自助：請對方使用登入頁 **忘記密碼？**。
- 若需協助：後台 **重設密碼**，將新臨時密碼交付對方。

### 情境 D：教材寄送作業
1. 學員於課程頁申請教材。
2. 後台 **教材管理** 查看申請 → 列印出貨單 → 寄出 → **確認已寄送**（多地址逐批次確認）。
3. 學員收到後在課程頁點「我已收到教材」，講師方可開始上課。

### 情境 E：協助講師處理課程
- 透過 **開課管理** 搜尋課程 → 另開課程詳情頁 → 可協助核准學員、結業、取消等（admin 具完整權限）。
