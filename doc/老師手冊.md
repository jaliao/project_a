## 一、講師身分與授課資格

系統用**兩層把關**決定您能開哪些課，兩層都通過才能真正開課：

### 第一層：開課入口（能不能看到「新增授課」）
> **依身分判定 = 具有 `teacher` / `admin` / `superadmin` 任一身分。**

- 具備上述身分者，個人首頁才會出現 **新增授課** 入口。
- 不具身分時入口會隱藏 / 停用，Server Action 也會擋下並回覆「需具講師身分方可開課」。

### 第二層：精靈內選課（能不能選某一門課來開）
進入新增授課精靈後，**Step 1 會逐門課檢查您是否有資格開設「該門課程」**：

> **可開設某課程 = 您是 admin / superadmin（豁免），或您已「結業該門課程本身」。**

- 例：要開「啟動靈人」，您必須**已結業「啟動靈人」本身**（非僅完成其先修）。
- 不符資格的課程卡片會呈現**灰階停用**，並顯示提示「須先完成{課程名稱}才能授課」。

### 兩層合起來的實際效果
| 您的情況 | 能否開課 |
|----------|----------|
| 有 teacher 身分，但**無任何結業證書** | 看得到入口，但精靈內**每門課都停用**，實際無法開課 |
| 有 teacher 身分，且**已結業「啟動靈人」** | 可開設「啟動靈人」（其他未結業的課仍停用） |
| admin / superadmin | 看得到入口，且**任何課程都可開**（第二層豁免） |

> 換言之，一般講師要真正開某門課，需**同時**具備講師身分（過第一層）**並**持有該課程的結業證書（過第二層）。
> 您的身分標籤會顯示在個人頁面，例如「啟動靈人 講師」「啟動豐盛 講師」（依結業證書推導，可同時有多個）。

## 二、開課流程總覽

```
新增授課（選課→基本資料→預覽）
        ↓
建立課程 → 邀請學員（連結 / 啟動編號）
        ↓
學員申請 → 講師核准（pending → approved）
        ↓
學員申請教材 → 管理者寄送 → 學員確認收件
        ↓
開始上課 → 授課 → 辦理結業
```

## 三、新增授課（三步驟精靈）

進入路徑：個人首頁點選 **新增授課**。

| 步驟 | 內容 |
|------|------|
| **Step 1 選擇課程** | 以卡片方式列出已啟用課程。系統會**逐門檢查您是否已結業該課程**（admin/superadmin 豁免）：未結業的課程卡片呈灰階停用，並顯示「須先完成{課程名稱}才能授課」，無法選取。詳見〈[一、講師身分與授課資格](#一講師身分與授課資格)〉的第二層說明。 |
| **Step 2 基本資料** | 填寫課程名稱（可編輯）、預計人數、開課日期、截止日期（選填）、備註。並可開啟 **公開媒合** 開關與填寫招募備註（見下節）。 |
| **Step 3 預覽確認** | 檢視整理後的摘要，確認無誤後送出建立課程。 |

建立成功後會進入**邀請學員**階段。

> 💡 測試環境另有 **新增測試授課** 按鈕（僅開發環境顯示），可一鍵建立一筆示範課程與 5 位測試學員，方便演練流程。

## 四、邀請學員

課程建立後，可用兩種方式邀請學員：

### 方式 1：分享課程連結
- 點選 **複製連結** 取得課程網址（`/course/{課程編號}`）。
- 支援系統分享面板（Web Share API），亦可直接複製到剪貼簿。
- 學員開啟連結後即可在課程頁申請加入。

### 方式 2：以啟動編號邀請
- 輸入學員的**啟動編號**送出邀請。
- 學員會在通知中心收到邀請訊息。

## 五、媒合布告欄（公開招生）

若希望讓全機構會員都能看到並報名您的課程：

1. 在**開課精靈 Step 2**，或事後於**課程詳情頁**開啟 **公開媒合** 開關。
2. 填寫**招募備註**（上限 500 字），說明招生對象、時間等資訊。
3. 開啟後，課程會出現在 **媒合布告欄**（`/match-board`），所有登入會員皆可瀏覽並申請。

> 課程詳情頁可隨時切換公開媒合狀態或編輯備註（`updateMatchSettings`，僅限該課程講師或管理者）。關閉公開媒合時備註仍會保留。
> 布告欄僅列出「公開媒合且未取消、未結業、未過截止日」的課程。

## 六、審核學員申請

1. 學員透過連結或布告欄申請後，您會收到**新申請通知**。
2. 進入 **課程詳情頁**，於學員清單中查看狀態為 **申請中（pending）** 的學員。
3. 點選 **核准**，學員狀態變為 **已開課（approved）**，並收到通知。

> 只有 approved 的學員才會出現在正式學員名單與結業名單中。

## 七、教材作業

教材由**學員自行申請**、**管理者寄送**，講師需留意流程節點：

1. 學員在課程頁 **申請教材**（選擇繁體 / 簡體、取貨方式）。
2. 管理者於後台確認**寄送**。
3. 學員收到後點選 **我已收到教材**。
4. ⚠️ **課程需在學員確認收件後**才能「開始上課」。

> 教材的書本數量由學員的選購（繁／簡體）自動統計，講師無需手動填寫。

---

## 八、開始上課

- 前置條件：教材已由學員確認收件（`receivedAt` 已設定）。
- 在**課程詳情頁**點選 **開始上課**。
- 課程狀態由「招生中」變為「進行中」，學員端課程卡片也會同步更新狀態。

---

## 九、辦理結業

進入路徑：課程詳情頁（課程需為**進行中**）點選 **結業申請** → 進入獨立結業頁面 `/course/{id}/graduate`。

三步驟流程：

| 步驟 | 內容 |
|------|------|
| **填寫** | 填寫**最後一堂課程日期**；勾選通過結業的學員（預設全選已核准學員）；未結業者需選擇原因（時間不足 / 其他）。 |
| **預覽** | 檢視結業名單與未結業名單。 |
| **送出** | 批次寫入結業結果。空名單無法送出。 |

完成後：

- 通過的學員會獲得**結業證明**，並在其個人頁顯示。
- 課程詳情頁新增 **結業資訊** 區塊（最後課程日期、已結業 / 未結業學員清單與原因）。
- 學員會收到結業通知。

> 結業是學員取得**進階課程報名資格**與**未來授課資格**的關鍵。

## 十、取消課程

1. 在**課程詳情頁**點選 **取消課程**。
2. 於確認 Dialog 中選擇取消原因（下拉選單），或自填說明。
3. 確認後課程狀態變為 **已取消**，相關學員會收到通知。

---

## 十一、課程 FAQ（回覆學員提問）

課程詳情頁最下方有「**課程 FAQ**」留言區，供學員公開提問、由您回覆：

- **任何登入會員都能提問**；有新提問時**您會收到 Inbox 通知**。
- **只有您（授課老師）能回覆**：在對應提問下方的輸入框打字、點 **送出回覆**。回覆後**發問者會收到通知**。
- 您的回覆會標示「**老師**」標記，顯示在該提問下方。
- **管理留言**：您可以**刪除課程內任意留言**（垃圾桶圖示 → 確認）；刪除提問會連同其下回覆一併刪除。學員只能刪自己的留言。
- FAQ 內容對所有可瀏覽課程頁的會員**公開可見**（非私訊）。

## 十二、課程詳情頁說明

`/course/{課程編號}` 是您管理單一課程的中心，包含：

- **基本資訊**：課程名稱、講師、開課 / 截止日期、狀態 Badge（招生中 / 進行中 / 已結業 / 已取消）。
- **學員名單**：已核准學員清單、待審核（pending）申請。
- **操作按鈕**（依角色與課程狀態顯示）：
  - 分享 / 複製連結（右上角）
  - 公開媒合切換與招募備註編輯
  - 核准學員
  - 開始上課（教材收件後）
  - 結業申請（進行中才顯示）
  - 取消課程
- **結業資訊**：已結業課程顯示最後課程日期與結業 / 未結業名單。

## 十三、常見問題

**Q：我看不到「新增授課」按鈕？**
A：您尚未具備授課資格。請確認您是否擁有 teacher/admin 身分，或已結業可開設的課程。

**Q：某個課程在精靈 Step 1 無法選取？**
A：開設該課程需**已結業該課程本身**。完成並取得該課程結業證書後即可開設。

**Q：學員一直無法「開始上課」？**
A：請確認學員已申請教材、管理者已寄送、且學員已點「我已收到教材」。

**Q：結業頁面送不出去？**
A：結業名單不可為空，請至少勾選一位通過結業的學員。

**Q：公開媒合關閉後，之前寫的招募備註會消失嗎？**
A：不會，備註會保留，下次開啟時仍在。
