# Design: cr-spec-260720-003 教材申請作業 UI 優化（三單元化）

## Context

`course-detail-actions.tsx` 的教材申請作業區塊在 cr-spec-260720-001 後包含：參考統計盒（總需求/已申請/尚未申請）、完成狀態列、訂單清單、動作按鈕與多種提示。目前為單一縱向堆疊、無分段標題；另有一輪未 commit 的按鈕調整（「無須額外申請」＋引導文字）待被本次取代。純前端呈現重構，actions／資料層／schema 皆不動。

## Goals / Non-Goals

**Goals:**
- 區塊內分三個具標題的單元：學員教材需求統計 → 教材申請進度 → 申請作業。
- 申請作業單元提供「申請注意事項」與逐顆「功能按鈕說明」，按鈕並列：「申請教材」｜「已完成申請」。
- 完成標記按鈕定名「已完成申請」，確認視窗標題同步。

**Non-Goals:**
- 不改任何 server action、開課門檻邏輯、資料查詢。
- 不改申請對話框（cr-260720-001 的逐本清單維持）。
- 不改訂單列內嵌資訊的欄位內容。

## Decisions

### D1：單元切分與內容歸屬

| 單元 | 內容 |
|------|------|
| ①學員教材需求統計 | 總需求（繁/簡）＋「依學員申請統計、僅供參考」註記 |
| ②教材申請進度 | 已申請、尚未申請（繁/簡）；「教材申請已完成」狀態列（含「重新開放申請」）；逐筆訂單清單；無訂單時空狀態文字 |
| ③申請作業 | 申請注意事項（含功能按鈕說明：申請教材＝開清單調整後送出；已完成申請＝不需再購買、標記後可開課）＋按鈕列「申請教材」｜「已完成申請」＋情境提示（已完成/已全數申請） |

單元標題以卡片內小標（`text-sm font-semibold`）呈現，維持單一 `Section` 卡片不拆卡（頁面仍是三大作業區塊：教材申請／開始上課／取消上課）。

### D2：按鈕命名「已完成申請」，說明文字承載引導語意

- 上一輪「無須額外申請」＋引導文字「或本次課程不需要再購買任何教材」廢除；語意移至功能按鈕說明（「已完成申請：本課程不需再購買任何教材時點選…」）。
- i18n：沿用 `course.material.finalizeButton` 等既有 key 改值；新增單元標題與說明 key（`sectionDemand`／`sectionProgress`／`sectionApply`／`applyNotesTitle`／`noteApplyButton`／`noteFinalizeButton`）；移除 `finalizeLeadIn`。
- 已完成時：「申請教材」停用、「已完成申請」隱藏（狀態列在單元②顯示完成狀態與「重新開放申請」）。

### D3：僅動 `course-detail-actions.tsx` 與 messages

無新元件檔；三單元以區塊內 JSX 分段實作。手冊按鈕名稱同步（老師／管理者），version patch +1。

## Risks / Trade-offs

- [與 cr-260720-001 同檔未歸檔疊改] → 本 change 的 delta spec 以「最終狀態」撰寫完整 requirement，歸檔順序 001 → 003 時以 003 為準。
- [按鈕名稱兩度更名造成手冊不一致] → 手冊全文 grep「無須額外申請」「完成教材申請」逐一改為「已完成申請」。
