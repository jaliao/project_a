## Why

需求單 CR-SPEC-260828-012（提出人：廖柏嘉 Justin，2026-08-28）：CR-SPEC-260828-009 已把「我的學習」改為「選書籍 → 課次卡片牆」兩層結構並補齊「啟動靈人」12 課大綱，但**啟動豐盛（`courseCatalogId = 2`）仍無大綱**，書籍卡片顯示為鎖定「尚未開放」。本單提供啟動豐盛完整 12 課的課次標題與分段查經經文清單，讓已解鎖啟動豐盛的學員可以開始撰寫分段查經。

## What Changes

- **`config/learning-outline.ts`**：`LEARNING_OUTLINE` 新增 `2`（啟動豐盛）的完整大綱，12 課（`lesson-01` ~ `lesson-12`），其中第一課無經文項目、其餘 11 課各 3 個經文項目。檔首註解同步更新（啟動豐盛已建置）。
- **其餘一律不變**：無 schema 變更、無新元件、無 server action / Zod / i18n 變更、無路由變更。書籍卡片頁對「啟動豐盛」的呈現由 CR-009 既有邏輯自動接手——`getCatalogOutline(2)` 有值後 `hasOutline = true`，卡片是否可進入改由「該學員在啟動豐盛是否已解鎖（有已開始的報名）」決定；未解鎖者顯示「尚未開課」鎖定（不再是「尚未開放」）。
